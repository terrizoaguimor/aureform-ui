# Integration provider brand assets

These files identify the services and projects named in the integration catalog. Logos and trademarks remain the property of their respective owners and are excluded from Aureform’s Apache 2.0 grant. Inclusion does not imply endorsement or a configured provider connection.

Original shapes, aspect ratios, colors and supplied neutral backgrounds are retained. There are no generated logos, recolored marks or cropped wordmarks. A source repository’s software license does not establish trademark permission. The [manifest](manifest.json) records actual sources, consultation dates, file hashes, normalization details and known usage boundaries. Sources were consulted on 21 October 2026.

Where an original React SVG uses `fillRule` or `clipRule`, the standalone file uses the corresponding `fill-rule` and `clip-rule` attributes. This preserves the intended rendering; path geometry and paint values remain unchanged.

Auth.js and React Email supply original raster brand assets. Their SVG containers embed the unmodified originals as data URIs so both the Aureform CLI and the shadcn text registry can copy them. These are portable raster assets, not traced vectors. The original WebP/PNG files are also included in the repository.

Provider or host brands are used for product/extension contexts where recorded in the manifest; this does not assert an independent product logo.

The [native Figma gallery](https://www.figma.com/design/lHp5p10yGb7lqXJDnAox0N?node-id=478-37714) uses reusable artwork and tile components. All 120 native artwork components are recorded in the [recovery receipt](https://github.com/terrizoaguimor/aureform-ui/blob/main/design/reports/native-integration-brands-recovery-2026-10-21.json), including 40 original alternatives. The selected gallery and Hub view passed native visual review; this is separate from browser or provider connectivity acceptance.

Figma uses the full-resolution raster originals. Auth.js required a lossless PNG encoding after the original WebP rendered blank in Figma: dimensions and decoded RGBA pixels are identical. The original public WebP and its portable SVG container remain unchanged. The two separately bundled smaller PNG references are optional preview derivatives, not the actual native master inputs.
