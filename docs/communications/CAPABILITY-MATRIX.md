## Cómo interpretar una capacidad

Las etiquetas describen la capacidad del proveedor para el perfil indicado; **«nativo» no significa «ya disponible en Aureform»**.

| Estado | Significado y límite |
| --- | --- |
| **Nativo** | Existe una API, SDK o servicio oficial que realiza la primitiva. Exige cuenta, recursos, configuración y adaptación de Aureform. |
| **Infraestructura adicional** | La experiencia requiere backend, almacenamiento, coordinación, transporte de medios o servicios adicionales. Puede componerse sobre primitivas nativas. |
| **Parcial** | Hay soporte acotado por país, dirección, número, modo, topología, navegador o funcionalidad. La restricción forma parte del contrato. |
| **No disponible** | Existe una exclusión explícita, una prohibición o la función queda fuera de esa plataforma. No equivale a «no encontramos documentación». |
| **No verificado** | Falta contrato suficiente, hay contradicción documental o no se comprobó la habilitación de la cuenta. No se transforma en soporte por inferencia. |

La **disponibilidad** se registra aparte: documentación pública, GA anunciada, beta explícita, habilitación condicionada por cuenta/región o desconocida. Un producto puede ser GA y conservar botones o regiones sujetos a beta.

La **evidencia** tiene un tercer eje:

- **D20:** documentación oficial consultada realmente el **2026-10-20**. Esta fecha se aplica a **cada URL de proveedor y hallazgo técnico** salvo relectura o fecha editorial expresamente diferenciada. Las relecturas oficiales de Meta y la reconciliación Figma del **2026-10-21** se identifican aparte.
- **R20:** documentos locales leídos ese día; describen antecedentes de Aureform, no aceptación de telecomunicaciones.
- **P0:** prueba real pendiente. **Todas las capacidades de proveedor de esta matriz tienen P0**; no existe un recibo autenticado de Aureform Communications.
- **Propuesta:** decisión o requisito de diseño. No es un hecho del carrier ni una implementación existente.

Se utilizaron Search Service y páginas primarias. Cuando Search Service devolvió 429 para Meta, se leyó la página pública oficial por HTTP sin autenticación. Algunos artículos de ayuda de Twilio expusieron su contenido mediante el resultado indexado oficial, mientras la apertura directa mostró un shell JavaScript; se conserva esa limitación de acceso. Las explicaciones son paráfrasis, no transcripciones extensas.

## Alcance GLOBAL: perfiles, no una promesa de elegibilidad

**Propuesta del plan:** matriz por perfiles globales y backend de referencia **Node/Docker portable**. **Orden de producto:** P1 voz entrante primero; runtime portable primero **dentro de P5 IA**. **Requisito del usuario:** fuente y paridad Figma obligatorias. El laboratorio US propuesto no define la cobertura del producto.

Un perfil deberá identificar proveedor, cuenta/subcuenta, país del número empresarial, país del destinatario, canal, tipo de número, dirección, modo de control y región de procesamiento. También requiere fecha de evidencia, límites, aprobaciones y estado de habilitación. La ubicación física del usuario y las jurisdicciones aplicables son dimensiones adicionales; no se deducen automáticamente del prefijo.
